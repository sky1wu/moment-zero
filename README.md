# 零矩协议

一款基于力矩平衡的轻量解谜游戏。把不同升力的气球放到 5×5 平台上，使横向与纵向总力矩同时归零。

在线体验：[GitHub Pages](https://sky1wu.github.io/moment-zero/)

## 功能

- 随机种子与三档难度
- 唯一解题目生成器
- 轴对称、中心对称与自由图形
- 100 关固定闯关模式，由易至难并支持浏览器本地续玩
- 每日一题
- 拖放、提示、撤销和完成记录

闯关进度保存在当前浏览器的本地存储中。刷新或下次打开会恢复当前关卡、棋盘、用时与解锁进度；清除站点数据或更换设备后不会自动同步。

闯关提示全程共用：初始 5 次，每首次通过 5 关恢复 1 次，最多保留 5 次。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

运行完整检查：

```bash
npm test
npm run lint
```

## GitHub Pages

`Deploy GitHub Pages` 工作流会在主分支更新时部署，并于每天 UTC 00:23 起错峰生成每日一题；若线上日期仍未更新，会在 UTC 00:53 与 01:23 自动重试。

每日种子由 Actions 中的 `DAILY_SEED_SECRET` 通过 HMAC-SHA-256 计算。仓库和网页只包含当天结果，不包含密钥或未来种子。
